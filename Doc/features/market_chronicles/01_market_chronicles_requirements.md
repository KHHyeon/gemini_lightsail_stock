Market Chronicles Requirements

1) 기능 요구사항 (Functional)

R1. 트리거 기반 작성

  - T-Day 작성 조건: VIX 경계 또는 지수 변동 임계 충족 시 작성.
  - Backfill: 최근 N일 이벤트 데이를 스캔해 과거 리포트/인덱스 구축.
  - 외부 인제스트 결과(예: Telegram Pipeline) 도 트리거 입력으로 사용될 수 있으나,
    Market Chronicles 는 외부 수집기를 직접 호출하지 않는다. 모든 외부 데이터는
    오케스트레이터가 위임/전달한 결과만 수용한다(관심사 분리).

R2. 의미 기반 검색

  - 단순 단어 겹침이 아닌 상황/행동 중심 매칭을 사용.
  - 컨텍스트 주입은 Top-N 유사 지침만 전달.

R3. 인덱스 스키마 v2 강제

  - 운영 스키마는 version=2.
  - v1 감지 시 B-Type(Pause) 또는 명시적 자동 마이그레이션 옵션 처리.

R4. 행동 지침 미리보기

  - 본문 열기 전 판단 가능한 action_preview를 유지.
  - 길이 제한 및 일관된 형식 준수.

2) 비기능 요구사항 (Non-Functional)

N1. 토큰/속도 최적화

  - AI 가독성 핵심 필드만 노출.
  - 내부 보조 필드(정밀 매칭용)는 비노출.

N2. 안정성

  - AI 실패/네트워크 장애 시 정규식/기본값 폴백.
  - 백필은 부분 실패 허용, 큐 기반 재개 가능.

N3. 무중단 운영

  - Pause 상태에서 재귀 호출 방지.
  - 사용자 완료 응답으로 검증 후 재개.

3) 운영 제약

  - Drive를 단일 소스 오브 트루스로 사용.
  - 변경은 설계 문서 선반영 후 코드 적용.
  - 변경 완료 시 Post-Update 문서 동기화 필수.
