# 프로젝트 기본 규칙
1. **기본 지침**: 모든 개발 및 설계 결정은 프로젝트 루트의 `GEMINI.md` 파일을 최우선으로 참고한다.
2. **언어**: 모든 대화, 설명, 코드 주석은 한국어로 진행한다.

# 코드 스타일 및 문자열 제한
1. **UTF-8 준수**: 작성되는 모든 파이썬 코드(`*.py`) 내에는 UTF-8 범위를 벗어난 특수 문자열의 삽입을 엄격히 금지한다.
2. **코드 내 이모지 금지**: 코드 본문, 변수명, 주석 등 소스 코드 파일 자체에는 이모지를 절대로 삽입하지 않는다.
3. **Slack 출력 예외**: 
   - 슬랙(Slack)으로 전송되는 메시지 문자열에는 가독성을 위해 이모지를 사용할 수 있다.
   - 단, 이 이모지는 코드 내에 직접 하드코딩하지 말고, 필요한 경우 유니코드 대피 문자(예: `\U0001F600`)를 사용하거나 외부 설정 파일에서 불러오는 방식을 권장한다.
4. **JSON 분석 금지**: 프로젝트 내의 모든 `.json` 파일은 분석 대상에서 제외한다. 해당 파일들의 내용을 읽거나 코딩에 참고하지 마라.
5. **env 분석 금지**: 프로젝트 내의 모든 `.env` 파일은 분석 대상에서 제외한다. 해당 파일들의 내용을 읽거나 코딩에 참고하지 마라.

# 요구사양 관리
1. 요구사양 변경이 발생하면 반드시 `GEMINI.md`(또는 `SPEC.md`)의 변경 이력(Change Log)을 먼저 업데이트한 후 코드를 수정한다.
